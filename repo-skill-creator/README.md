# Repo Skill Creator

このスキルは、OpenAI公式の `skill-creator` を土台に、このリポジトリでスキルを作成・更新するためのルールを加えます。スキルごとのREADME作成とルートREADMEの一覧更新を支援します。

## 使い方

このリポジトリに新しいスキルを追加するとき:

```text
Use $repo-skill-creator to create a skill for [workflow] in this repository.
```

既存スキルを更新するとき:

```text
Use $repo-skill-creator to update [skill-name] and keep its README and the root index in sync.
```

詳しい作成ルールは [SKILL.md](SKILL.md) を参照してください。
