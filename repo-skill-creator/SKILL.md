# このリポジトリのスキルを作成・更新する

## 公式skill-creatorを土台にする

- このリポジトリ向けの新規スキル作成・既存スキル更新に使う。
- 利用できる場合は、作業前にOpenAI公式の `skill-creator` を読み、その命名、スコープ、構成、リソース選択、検証の方針に従う。公式手順をこのスキルへ複製せず、以下のリポジトリ固有ルールを追加で適用する。
- 公式スキルが利用できない場合も、依頼の範囲を守り、必要なファイルだけを作成・更新する。
- `SKILL.md` のfrontmatter、本文、補助リソースは公式ガイドに従って設計する。明示的な依頼がない限り、暗黙の呼び出しを無効にしない。

## 作成場所

- 依頼で別の場所が指定されていなければ、このリポジトリのルート直下に `<skill-name>/` を作る。`sync.sh` はルート直下の `SKILL.md` を持つディレクトリを同期する。
- ユーザーが別の作成場所を明示した場合は、その指定を優先する。リポジトリ外に作成した場合、このリポジトリのルートREADMEは変更しない。
- リポジトリ内でもルート直下以外を指定された場合は、その場所を尊重する。ただし、現在の `sync.sh` の自動同期対象ではないことを伝える。
- 既存のスキルを初期化し直さない。新規作成時は、利用可能なら公式initializerを使い、必要のない `scripts/`、`references/`、`assets/` は追加しない。

## スキルごとのREADME

- 作成するスキルには `README.md` を用意する。既存スキルを更新する場合は、READMEがなければ作成し、目的や利用方法に変更があれば内容を更新する。
- READMEは日本語を基本とし、スキルの目的と利用例を簡潔に記載する。ユーザーが別の言語を指定した場合は、その指定に従う。
- 利用例は `$skill-name` を含む実際に使える依頼文にする。詳細な手順や運用ルールは `SKILL.md` または必要な参照資料に置き、READMEと重複させない。
- 既存READMEがある場合は内容を確認し、依頼と関係のない記述を置き換えない。

## ルートREADMEの一覧

- リポジトリ内に作成したスキルを、ルート `README.md` の既存「スキル一覧」テーブルへ追加する。スキル名からスキル固有の `README.md` にリンクし、説明にはfrontmatterの `description` を簡潔に反映する。
- 既存スキルを更新したときは、名前・用途・説明に変更がある場合に一覧のリンクと説明も更新する。変更がない行は維持する。
- リポジトリ外に作成する場合は一覧を変更しない。リポジトリ内の別階層に作成する場合は一覧へ追加するが、`sync.sh` の対象外であることをユーザーに伝える。
- READMEを編集するときは現在の構成と表記を保ち、無関係な内容を変更しない。

## 完了前の確認

- 新規または大きく変更したスキルは、公式 `skill-creator` が案内する方法で検証する。validatorが利用できる場合は対象のスキルに対して実行する。
- スキルREADMEとルート一覧のリンク先、スキル名、説明が実際のファイルと一致することを確認する。
- 作成・更新したファイルと、検証した場合はその結果を簡潔に報告する。
